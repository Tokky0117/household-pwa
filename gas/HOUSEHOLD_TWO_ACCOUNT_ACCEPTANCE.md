# 夫婦2アカウントの同一家庭アクセス：受入手順

更新：2026-11-01 ／ 対象：開発ブランチ `stage-a-ui-handoff-review`

> 状態：認証済みの家庭接続診断 `household.status` とPWA設定UI、オフライン模擬試験まで実装。**実際の2アカウント／Google Sheets／iPhoneでの受入は未実施。** 本手順はデータ登録・書込許可を意味しない。

## 目的・前提

- 夫婦それぞれ自分のGoogleアカウントでログインし、同一の `households.household_id` に一意に紐づいていることを確認する。**ChatGPTの共有プロジェクトへの参加と、くらしストック用Google認証・家庭所属は別物**。
- `users` シートには `user_id`、`household_id`、`display_name`、`auth_subject` がある。Google subjectの認証・所属判定はGASのみで行い、**ブラウザで別ユーザーのsubjectやメールアドレスを表示しない**。
- 共有設定の誤紐付けで他家庭データを見せないことを優先する。自動招待、任意の家庭への参加、認証IDの手入力、家庭情報の自己申告による切替は実装しない。
- `household.status` は読み取り専用の空パラメータAPI。本人認証済みの家庭識別子・登録人数・2人登録かどうか・レシート書込不可のみ返す。登録人数が2であっても、**意図した配偶者本人であることは確認できない**。

## 隔離環境での受入項目（実行前に承認が必要）

- [ ] 専用の試験シート／GASデプロイが用意され、main・実家庭データとは分離されている。日用品・レシートの書込ゲートは閉じたまま。
- [ ] 管理者が同意のある2人のGoogleアカウントを、同一の試験家庭に一意に登録したことを確認。認証情報やsubjectをチャットに貼らない。
- [ ] 1人目が設定画面「自分の家庭への接続を確認」を押し、ログイン済みで家庭識別子・登録人数2・書込不可が表示される。
- [ ] 1人目がログアウトした後、2人目が**本人の端末で**同じ操作を行う。両者の家庭識別子が一致することを本人同士で照合する。
- [ ] 別家庭の試験アカウントでは別の家庭識別子が返り、他家庭のレシート／商品／店舗が一切表示されない。
- [ ] 共有家庭の2人がそれぞれ `record.list` を読み、同じ完成済みレシートだけを閲覧できる。作成途中、改変、不整合のあるレシートは表示されない。
- [ ] ログアウト・アカウント切替・タブ移動の途中で旧アカウントのデータが残らず、遅延応答も画面に採用されない。
- [ ] `household.status` に未知フィールドや家庭IDを指定すると拒否され、APIからGoogle subject・メール・他の利用者名が返らない。
- [ ] 通信失敗／古いGASデプロイ時は「確認失敗」と表示され、家庭を勝手に新規作成・切替しない。
- [ ] iPhone Safari／ホーム画面追加PWAの両方で読取・戻る・再ログインの操作性を確認。
- [ ] 別途承認した隔離試験で、レシート親・明細の途中失敗／再送を実Google Sheetsで故障注入し、同じ操作ID以外は重複登録しないことを確認。

## 現在の未解決事項と安全条件

- 正式な**2人目の招待・参加・取消の管理UI**は未実装。誤登録が疑われる場合、本人確認済みの管理者が隔離環境の家庭所属を点検するまでは保存を有効化しない。
- 現在の開発プレビューではGoogleログイン自体を停止しており、`household.status` のボタンを使った実接続確認はできない。
- レシート `record.create` の公開入口は常に拒否し、`RECEIPT_BATCH_WRITE_ENABLED=false`。GAS内部の隔離試験専用書込処理を、夫婦の正式な保存用として直接使わない。
- 受入記録には日時・テスト家庭・成否と不具合のみを残す。認証トークン・Google subject・家族のメールアドレス・レシート画像を記録に複写しない。
