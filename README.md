# くらしストック — 段階A UI試作

`household_pwa_requirements_basic_design(1).md`（2026-10-14 版）に沿った、依存パッケージ不要の静的PWAです。

## 起動

このフォルダで `py -m http.server 8000` を実行し、ブラウザで `http://localhost:8000` にアクセスします。iPhone実機ではHTTPSでの配信が必要です。iPhone Safariから「ホーム画面に追加」でPWA表示を確認できます。

## 実装済み

- 共通UI・4タブ・下部ナビ・ライト／ダーク・セーフエリア対応
- 日用品一覧、固定5カテゴリ、折り畳み、検索、在庫なしフィルタ、在庫あり／なし切替
- 同一カテゴリ内での上下移動、日用品追加・編集、正規化名の重複防止
- 日用品詳細、お気に入り仮登録・順序変更、比較期間の切替、比較単位、メモ
- 非表示と同名再登録時の再表示／新規登録ダイアログ
- 端末内localStorageでの試作用データ保持と初期化
- PWA manifest / Service Worker による静的アセットのキャッシュ

## 未実装・注意

Google Sheets / GAS、認証、夫婦間同期、IndexedDB、OCR、レシート、家計簿集計、実価格・店舗履歴は未実装。レシート／家計簿／設定の主要機能はプレースホルダーです。

**試作データは正本ではありません。** 保存はこのブラウザの localStorage のみで、別端末に共有されません。実際の家庭データやレシート情報を投入しないでください。

非表示同名での新規登録時の「旧商品の紐付け解除」は、商品データ自体がまだないため未実装です。本番ではGAS側の原子的な操作・同時更新制御が必要です。最安値は `—` と表示し、架空の価格は提示しません。

## v1.1 修正
- 検索欄を入力のたびに再描画しないよう修正。ローマ字入力・日本語IME変換時の入力継続を改善。
- カテゴリ見出しの背景・左線・文字色・太さを変更し、日用品行と区別。
- 上部の買い足し件数・全件数の大きなサマリーカードを削除。
- 追加は画面右上の「＋」、並び替えは一覧の「並び替え」、非表示は詳細の「⋯」から利用できます。
- 既存の端末内データは原則引き継ぎます。
- Windowsではこのフォルダー（index.htmlがある場所）で `py -m http.server 8000` を実行。


## v1.2 UI変更

- 並び替えを押した後、右端の≡をタッチドラッグ。同じカテゴリ内のみ変更。実iPhoneで操作確認が必要。

- 詳細の⋯メニュー順は編集、削除、お気に入り、登録商品、単位。
- 削除確認の文面とボタン順を変更。
- 入力フォームのヘッダーから戻るを外し、キャンセル／保存に統一。
- 比較数量はiPhoneでdecimal入力を促す。比較単位は個数・包装→容量→重量順に選択。
- 比較価格・OCR・夫婦間同期は引き続き未実装。

## v1.3 UI更新
- 検索欄の案内順を「日用品・商品・店舗・メモ」に変更。
- 詳細メニュー／遷移画面の表記を「日用品を編集／日用品を削除／お気に入りの管理／登録商品の管理／比較単位の設定」に統一。
- 比較単位は「個、本、枚、g、kg、mL、L」。旧データで他単位が保存されていた場合は比較単位の設定から変更してください。
- iPhoneは行を約0.4秒長押しして移動し、指を離すと表示順のみ保存します。PCではマウス長押しで同様に動きます。並び替えボタン・ハンドルなし。検索／在庫なしフィルタ中は並び替え不可。同じカテゴリ内のみ移動可能。
- お気に入りの管理も長押し並び替えに統一。商品やお気に入りの紐付け自体は変更しません。
- 削除ポップアップでは赤い「日用品を削除」と通常の「キャンセル」を上から配置。削除は非表示処理であり、独立したバックアップファイルではありません。
- ブラウザで `http://localhost:8000` を開くとPC確認ができます。iPhoneでは同一Wi-FiのWindows PCのIPv4アドレスとポート8000で接続できますが、Windows Defender Firewallで許可が必要な場合があります。ホーム画面へのPWAインストール・Service Workerの動作にはlocalhost以外では原則HTTPSが必要です。
- いずれの端末も実機でのドラッグ挙動の検証は未実施。端末ごとにlocalStorageは独立しています。同期・認証は未実装です。

## 段階A UI整理・引き継ぎ（2026-10-15）

### 確認できた実装範囲
- 静的PWA（`index.html` / `app.js` / `styles.css` / `manifest.webmanifest` / `sw.js`）。**React/TypeScriptではなく素のJavaScriptによる試作**です。後工程での採用・移行方針は別途判断してください。
- 固定5カテゴリ、日用品一覧・詳細・追加・編集・非表示、検索、在庫切替、カテゴリ内長押し並び替え。
- お気に入りの仮入力・並び替え、比較単位、メモ、ライト／ダーク、4タブの画面枠。
- localStorageで端末内試作データを維持。商品・店舗・最安値は実バックエンド未接続。

### 今回の修正
- 日用品追加・編集と比較単位のフォームで変更がある場合、キャンセル時に「変更を破棄／編集を続ける」を表示。入力中のフォームを確認画面に置き換えず保持。
- タッチ長押し並び替えでは、Safariのタッチ識別子をPointer Capture APIに渡さないよう整理。

### 共通UIルール
1. 戻る：詳細から一覧へ。編集画面で未保存の変更があるときだけ破棄確認。キャンセルは保存しない。保存は入力検証後に確定する。
2. 見出しと詳細メニュー：『日用品を編集』『日用品を削除』『お気に入りの管理』『登録商品の管理』『比較単位の設定』を統一。削除は**非表示**であり、商品・購入履歴の削除ではない。
3. 重要操作はラベル付きボタン、補助操作は右上の「⋯」に配置。同じ意味には同じアイコンを使う。主要タップ領域は原則44 CSS px以上。
4. 長押し並び替えは約420 ms、同一カテゴリ内に限定。通常スクロールで意図せず並び替えない。検索・在庫なしフィルタ中は並び替え不可。お気に入りにも同様の長押しを適用。
5. カテゴリ順固定（飲食、キッチン、洗面・風呂、洗濯・掃除、その他）。日用品一覧は在庫情報を中心にし、詳細はお気に入り→全商品最安値→メモ。価格と購入店・購入日は実購入データ導入後に表示。
6. フォント・色・ボタン・余白は共通CSSを使い、iPhoneのセーフエリアとライト／ダークに配慮する。

## ブランチ別 HTTPS プレビュー（GitHub Pages）

GitHub Actions の `.github/workflows/pages-previews.yml` がブランチへの push 時に、`main` と各作業ブランチの静的画面をまとめて公開します。追加のホスティング契約・APIキーは不要です。

**GitHubで最初に1回だけ設定**：リポジトリの **Settings → Pages → Build and deployment → Source: GitHub Actions** を選択してください。ワークフローの実行を許可し、Actions の実行結果を確認します。Pagesの設定はチャットから自動変更できません。

公開URL（公開設定とActions成功後）:
- `main`: https://tokky0117.github.io/household-pwa/
- 段階Aの作業ブランチ: https://tokky0117.github.io/household-pwa/previews/stage-a-ui-handoff-review/
- その他: `https://tokky0117.github.io/household-pwa/previews/<branch-slug>/`

ブランチ名のスラッシュなど英数字・ピリオド・アンダースコア・ハイフン以外はハイフンに置換してURLにします。新規ブランチにもworkflowファイルを含めてください（通常はmainから作れば自動的に含まれます）。プレビューは**パスごとに別画面**ですが、localStorageとブラウザのキャッシュは同一オリジンになる点に注意してください。試作用のデータ以外を入力しないでください。

ブランチを削除した場合でも、最後に公開したプレビューURLが残る可能性があるため、後日クリーンアップ処理を追加するまで、不要なプレビューは公開されたままになり得ます。すべてのページは公開URLです。認証を作るまでは家計データを入力しないでください。

## 段階A 追加調整（参考画像ベース）
- 日用品の**編集保存後は直前の日用品詳細画面へ戻る**。新規追加保存後は従来どおり日用品一覧へ戻る。
- iPhoneの参考画像に合わせ、共通の配色トークンをニュートラルな薄いグレー背景・白カード・濃い文字・青の操作色へ変更。
- 在庫ありはニュートラルグレー、在庫なしは淡いオレンジで強調。カテゴリ見出しの青い面・左線を除去し、落ち着いたグレー表示へ変更。
- メニュー、レシート画面など既存の機能・画面遷移は変更しない。レイアウト全体の模倣や新しいフィルタ機能の追加は今回の対象外。
- iPhone Safariの見え方、ライト／ダーク切替、既存データ維持を実機で再確認する。

## 段階A 一覧操作性の仕上げ（2026-10-15）
- Safariのボタン／フォーム関連要素をタップした瞬間の灰色ハイライトを抑制（キーボードフォーカスの輪郭は維持）。
- 日用品カードの高さ・上下間隔、カテゴリ見出しの余白を縮小し、一覧の縦スクロール量を減らした。
- 日用品名は17px・太字にして識別しやすくした。
- 行末の詳細矢印を廃止。**日用品名をタップして詳細へ**、在庫ボタンは従来どおり在庫切替。並び替えは同カテゴリ内で長押し。
- iPhone Safari実機で、誤タップ・スクロール・ドラッグの干渉がないかを確認する。
