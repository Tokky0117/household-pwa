# くらしストック — 段階A UI試作

`household_pwa_requirements_basic_design(1).md`（2026-10-14 版）に沿った、依存パッケージ不要の静的PWAです。

## 起動

このフォルダで `py -m http.server 8000` を実行し、ブラウザで `http://localhost:8000` にアクセスします。iPhone実機ではHTTPSでの配信が必要です。iPhone Safariから「ホーム画面に追加」でPWA表示を確認できます。

## 実装済み

- 共通UI・4タブ・下部ナビ・ライト／ダーク・セーフエリア対応
- 日用品一覧、固定5カテゴリ、折り畳み、検索、在庫なしフィルタ、在庫あり／なし切替
- 同一カテゴリ内での上下移動、日用品追加・編集、正規化名の重複防止
- 日用品詳細、お気に入り仮登録・順序変更、比較期間の切替、比較単位、メモ
- 非表示と同名再登録時の再表示／新規登録ダイアログ
- 端末内localStorageでの試作用データ保持と初期化
- PWA manifest / Service Worker による静的アセットのキャッシュ

## 未実装・注意

Google Sheets / GAS、認証、夫婦間同期、IndexedDB、OCR、レシート、家計簿集計、実価格・店舗履歴は未実装。レシート／家計簿／設定の主要機能はプレースホルダーです。

**試作データは正本ではありません。** 保存はこのブラウザの localStorage のみで、別端末に共有されません。実際の家庭データやレシート情報を投入しないでください。

非表示同名での新規登録時の「旧商品の紐付け解除」は、商品データ自体がまだないため未実装です。本番ではGAS側の原子的な操作・同時更新制御が必要です。最安値は `—` と表示し、架空の価格は提示しません。

## v1.1 修正
- 検索欄を入力のたびに再描画しないよう修正。ローマ字入力・日本語IME変換時の入力継続を改善。
- カテゴリ見出しの背景・左線・文字色・太さを変更し、日用品行と区別。
- 上部の買い足し件数・全件数の大きなサマリーカードを削除。
- 追加は画面右上の「＋」、並び替えは一覧の「並び替え」、非表示は詳細の「⋯」から利用できます。
- 既存の端末内データは原則引き継ぎます。
- Windowsではこのフォルダー（index.htmlがある場所）で `py -m http.server 8000` を実行。


## v1.2 UI変更
- 日用品名・メモ・お気に入り名称に加え、仮の商品名・チェーン名を検索。実際のproducts/stores検索はバックエンド連携時に置換。
- 並び替えを押した後、右端の≡をタッチドラッグ。同じカテゴリ内のみ変更。実iPhoneで操作確認が必要。
- 新規追加は該当カテゴリを展開して追加行へスクロール、ハイライト表示。
- 詳細の⋯メニュー順は編集、削除、お気に入り、登録商品、単位。
- 削除確認の文面とボタン順を変更。
- 入力フォームのヘッダーから戻るを外し、キャンセル／保存に統一。
- 比較数量はiPhoneでdecimal入力を促す。比較単位は個数・包装→容量→重量順に選択。
- 比較価格・OCR・夫婦間同期は引き続き未実装。

## v1.3 UI更新
- 検索欄の案内順を「日用品・商品・店舗・メモ」に変更。
- 詳細メニュー／遷移画面の表記を「日用品を編集／日用品を削除／お気に入りの管理／登録商品の管理／比較単位の設定」に統一。
- 比較単位は「個、本、枚、g、kg、mL、L」。旧データで他単位が保存されていた場合は比較単位の設定から変更してください。
- iPhoneは行を約0.4秒長押しして移動し、指を離すと表示順のみ保存します。PCではマウス長押しで同様に動きます。並び替えボタン・ハンドルなし。検索／在庫なしフィルタ中は並び替え不可。同じカテゴリ内のみ移動可能。
- お気に入りの管理も長押し並び替えに統一。商品やお気に入りの紐付け自体は変更しません。
- 削除ポップアップでは赤い「日用品を削除」と通常の「キャンセル」を上から配置。削除は非表示処理であり、独立したバックアップファイルではありません。
- ブラウザで `http://localhost:8000` を開くとPC確認ができます。iPhoneでは同一Wi-FiのWindows PCのIPv4アドレスとポート8000で接続できますが、Windows Defender Firewallで許可が必要な場合があります。ホーム画面へのPWAインストール・Service Workerの動作にはlocalhost以外では原則HTTPSが必要です。
- いずれの端末も実機でのドラッグ挙動の検証は未実施。端末ごとにlocalStorageは独立しています。同期・認証は未実装です。
