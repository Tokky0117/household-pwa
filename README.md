# くらしストック — 段階A UI試作

> **共通UIの最新設計方針は [UI_GUIDELINES.md](./UI_GUIDELINES.md) を正本とします。** 以下には過去の検討・変更履歴も含まれています。新規画面での部品・配置・操作はガイドラインを優先してください。

`household_pwa_requirements_basic_design(1).md`（2026-10-14 版）に沿った、依存パッケージ不要の静的PWAです。

## 起動

このフォルダで `py -m http.server 8000` を実行し、ブラウザで `http://localhost:8000` にアクセスします。iPhone実機ではHTTPSでの配信が必要です。iPhone Safariから「ホーム画面に追加」でPWA表示を確認できます。

## 実装済み

- 共通UI・4タブ・下部ナビ・ライト／ダーク・セーフエリア対応
- 日用品一覧、固定5カテゴリ、折り畳み、検索、在庫なしフィルタ、在庫あり／なし切替
- 同一カテゴリ内での上下移動、日用品追加・編集、正規化名の重複防止
- 日用品詳細、お気に入り仮登録・順序変更、比較期間の切替、比較単位、メモ
- 非表示と同名再登録時の再表示／新規登録ダイアログ
- 端末内localStorageでの試作用データ保持と初期化
- PWA manifest / Service Worker による静的アセットのキャッシュ

## 未実装・注意

Google Sheets / GAS、認証、夫婦間同期、IndexedDB、OCR、レシート、家計簿集計、実価格・店舗履歴は未実装。レシート／家計簿／設定の主要機能はプレースホルダーです。

**試作データは正本ではありません。** 保存はこのブラウザの localStorage のみで、別端末に共有されません。実際の家庭データやレシート情報を投入しないでください。

非表示同名での新規登録時の「旧商品の紐付け解除」は、商品データ自体がまだないため未実装です。本番ではGAS側の原子的な操作・同時更新制御が必要です。最安値は `—` と表示し、架空の価格は提示しません。

### 確認できた実装範囲
- 静的PWA（`index.html` / `app.js` / `styles.css` / `manifest.webmanifest` / `sw.js`）。**React/TypeScriptではなく素のJavaScriptによる試作**です。後工程での採用・移行方針は別途判断してください。

### 今回の修正
- 日用品追加・編集と比較単位のフォームで変更がある場合、キャンセル時に「変更を破棄／編集を続ける」を表示。入力中のフォームを確認画面に置き換えず保持。
- タッチ長押し並び替えでは、Safariのタッチ識別子をPointer Capture APIに渡さないよう整理。

### 共通UIルール
1. 戻る：詳細から一覧へ。編集画面で未保存の変更があるときだけ破棄確認。キャンセルは保存しない。保存は入力検証後に確定する。
2. 見出しと詳細メニュー：『日用品を編集』『日用品を削除』『お気に入りの管理』『登録商品の管理』『比較単位の設定』を統一。削除は**非表示**であり、商品・購入履歴の削除ではない。
3. 重要操作はラベル付きボタン、補助操作は右上の「⋯」に配置。同じ意味には同じアイコンを使う。主要タップ領域は原則44 CSS px以上。
4. 長押し並び替えは約420 ms、同一カテゴリ内に限定。通常スクロールで意図せず並び替えない。検索・在庫なしフィルタ中は並び替え不可。お気に入りにも同様の長押しを適用。
5. カテゴリ順固定（飲食、キッチン、洗面・風呂、洗濯・掃除、その他）。日用品一覧は在庫情報を中心にし、詳細はお気に入り→全商品最安値→メモ。価格と購入店・購入日は実購入データ導入後に表示。
6. フォント・色・ボタン・余白は共通CSSを使い、iPhoneのセーフエリアとライト／ダークに配慮する。

- 公開成功は動作保証ではない。追加と編集の保存、重複チェック、未保存確認、iPhoneのキーボード表示、表示密度、フィルタと検索の組み合わせを実機で確認する。

## 段階A 最安値表示とその他の設定（2026-10-16）
- 詳細画面の最安値見出しを「最安値」に変更し、対象を「お気に入り」「全商品」の切替表示とする。期間（直近3か月／全期間）と通常時・割引時の価格表示は共通。お気に入りは登録済み商品／チェーンのみを比較対象とする想定。GASと購入履歴未実装の試作中は、どちらも「購入履歴なし」を示し金額は算出しない。
